About This Demo Reel

I made this for my senior show where we showed off our capstone games that we've been working on all year. For this reel I focused on my role as a UI and Systems programmer, highlighting my main contributions to the overall project.

Technical Highlights

  • Quest System
    • Fully functional and additive quest system. Easy for designers to add new quests and edit values, such as the reward and level needed to reach.
  • Camera Detection
    • Everything from critters to landmarks gets picked up with the detection. When it is completely in the frame, a UI symbol will appear to let you know that you have properly taken its picture.
  • Diegetic UI
    • Both the quest board and the journal are fully diegetic. Everything is using static meshes with widgets attached so that the player can feel as if they are really in the world while interacting with the magazines and their journal.
